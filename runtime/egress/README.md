# sealed-egress

The only container on both the `apps` and `edge` networks of a deployment VM. It is the HTTP(S) proxy and the DNS server for every other container, and it enforces the per-caller allowlists that are part of the measured stack (spec 5.4, INTERFACES sections 12 and 14).

- Proxy (`listen.proxy`, default `:3128`): HTTP `CONNECT` tunnels and absolute-URI `http://` forwarding. Built on [stripe/smokescreen](https://github.com/stripe/smokescreen) embedded as a library. No TLS interception.
- DNS (`listen.dns`, default `:53`, UDP and TCP): answers A/AAAA only for names on the caller's allowlist, forwards them to `upstreamDns`, NXDOMAIN for everything else.
- Stats (`listen.stats`, default `:9100`): `GET /v1/stats` for `statsReaders` only, `GET /healthz` for anyone.

## Run

```
sealed-egress [-config PATH]                 # serve
sealed-egress [-config PATH] -check          # validate the config, print its sha256, exit
sealed-egress [-config PATH] -healthcheck    # probe the local /healthz (compose healthcheck)
```

The config path is `-config`, else `$SEALED_EGRESS_CONFIG`, else `/etc/sealed/egress.json`. SIGINT or SIGTERM stops accepting, drains open tunnels for up to 15 seconds and logs a final counts line. Proxy environment variables are removed at startup (goproxy would otherwise chain through them).

Image: `docker build -f runtime/egress/Dockerfile .` from the repo root (multi-stage, pinned `golang:1.27.3-trixie` and `distroless/static-debian13:nonroot`, CGO off, `-trimpath -buildvcs=false`, empty build id). Binding port 53 as nonroot relies on Docker's default `net.ipv4.ip_unprivileged_port_start=0`; do not override that sysctl.

## Config

Canonical JSON (INTERFACES section 1), generated by the composer and measured. Parsing is strict: the bytes must be canonical, every key is required with exact case (arrays may be empty), unknown keys are errors.

```json
{"allowedPrivateCidrs":[],"callers":[{"allow":["sealed-key-broker-xyz.a.run.app:443"],"ip":"172.30.0.3","name":"sealed-agent"}],"listen":{"dns":":53","proxy":":3128","stats":":9100"},"statsReaders":["172.30.0.3"],"upstreamDns":["8.8.8.8:53"]}
```

- `callers[].ip` is the caller's fixed container IP; the source IP of each connection selects the caller. Unknown sources are denied.
- `callers[].allow` entries are `host:port`, `*.domain:port` (exactly one extra label, never the apex) or `a.b.c.d:port`. Hosts are lowercase ASCII (punycode), at least two labels, no trailing dot. Only listed ports are reachable. Wildcards over an ICANN public suffix (`*.com`) and IPv6 literals are rejected. Raw IP entries must be public or inside `allowedPrivateCidrs`. Entries must be unique per caller.
- `allowedPrivateCidrs` may only open ranges inside 10/8, 172.16/12, 192.168/16, 100.64/10 (CGNAT) and fc00::/7 (ULA).
- `upstreamDns` is 1 to 8 `ip:port` values.

The `policy` package has no proxy or DNS dependencies, so the composer can build configs with `policy.Config`, `policy.EncodeCanonical` and `(*policy.Config).Validate`.

## Destination checks

Applied after resolution to every address, and again just before the dial; only the checked IP is dialed (DNS rebinding safe).

| always denied | denied unless in `allowedPrivateCidrs` |
|---|---|
| metadata (169.254.169.254, fd20:ce::254, fd00:ec2::254), loopback, link-local (169.254/16, fe80::/10), 0/8, multicast, 240/4, NAT64 (64:ff9b::/96, 64:ff9b:1::/48), 6to4, Teredo, IPv6 outside 2000::/3, the egress container's own addresses | 10/8, 172.16/12, 192.168/16, 100.64/10, fc00::/7 |

Absolute `https://` URLs (which would make the proxy speak TLS for the client) and client-chosen upstream proxies (`X-Upstream-Https-Proxy`) are refused.

Denials are `403 Forbidden` with header `X-Sealed-Egress: blocked`. Upstream failures stay `502`/`504` and are not counted as blocked.

## DNS answers

| query | answer |
|---|---|
| A/AAAA for a name on the caller's allowlist (any port) | forwarded; addresses in denied ranges are stripped and counted as blocked |
| other types for an allowed name | NOERROR, no records (never forwarded) |
| ANY or a non-IN class for an allowed name | REFUSED, counted |
| any type for any other name | NXDOMAIN, counted |
| any query from an unknown source | REFUSED, counted |

UDP replies are truncated to the client's buffer (512 bytes, or its EDNS0 size up to 4096) with TC set, so the client retries over TCP. Upstream answers with TC are retried over TCP. Upstream servers are tried in rotation with failover.

## Stats

```json
{"since":1730000000,
 "allowed":{"api.example.com:443":12,"*.cdn.example.net:443":3},
 "blocked":{"*.evil.com:443":2,"169.254.169.254:80":1,"*.evil.com:53":40},
 "callers":{"scraper":{"allowed":{...},"blocked":{...}}}}
```

`allowed` and `blocked` aggregate all callers (the INTERFACES shape); `callers` breaks them down by caller name (`(unknown)` for unknown sources). Keys never carry paths, queries or payloads, and are bounded:

- allowed: the allowlist entry that matched (`*.cdn.example.net:443`, not the full host).
- blocked, name on the caller's allowlist: that entry's pattern with the requested port (`api.example.com:22`, or `rebind.example.com:443` when an allowed name resolved to a denied address).
- blocked, any other name: reduced to its registrable domain (`x7f3a.evil.com` becomes `*.evil.com:443`), so a blocked name cannot smuggle data into counts that leave the VM, and random subdomains collapse into one key.
- DNS lookups use port 53 (`*.evil.com:53`).
- After 256 distinct keys per caller and verdict, further keys count under `other:0`.

The same counts (for the last interval) are logged once a minute as one JSON line, `{"msg":"egress counts","interval_s":60,"allowed":n,"blocked":m,"callers":{...}}`. Smokescreen's per-request logs are discarded.

## Tests

```
go test -race ./runtime/egress/...
```

Unit tests cover config validation, matching, IP classes, stats, the upstream client and the DNS server. `egress_test.go` runs the whole service on 127.0.0.1 random ports with local HTTP and HTTPS upstreams and a fake upstream DNS server. Two test-only hooks in `egress.Options` make that possible on one host: `SourceIP` (maps client source ports to caller IPs) and `Dial` (routes dials for fake public IPs to the local servers, after every check). Production leaves both nil.
